# 关于充值和提现审核的细节

1. 目前的上下级流程是：超管-管理员-1用户（代理商）-2用户（代理商）-3用户（代理商）-n用户。相当于无限制层级代理。
2. 充值和提现的审核流程是：如果1用户（代理商）给2用户代理商充值或者提现，需要1用户代理商的上级来审核。1用户的上级代理商可以是管理员，也可以是用户（代理商），如果没有上级默认是超管审核。
3. 如果2用户（代理商）给3用户代理商充值或者提现，需要2用户代理商的上级1用户来审核。
4. 如果3用户（代理商）给n用户代理商充值或者提现，需要3用户代理商的上级2用户来审核。
5. 如果是管理员给1用户（代理商）充值或者提现，则需要超管审核。
