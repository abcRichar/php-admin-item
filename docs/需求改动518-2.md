# 需求改动
  1. 用户抢单不用按照第二天自动关闭更新任务了，改为手动，用户设置页面上的更新任务开关可以去掉，新增两个手动开关：归零开关和任务开关。
    1. 归零开关：后台上级点击该开关后，将当天的完成数量归零。不点就不归0，然后到0点了也不用自动归0。
    2. 任务开关：后台上级开起后才能继续抢单，关闭就不能抢单。
    3. 注意：就算是任务开关开启，如果用户已经60单，然后后台没有手动归0，那么还是无法抢单的，只能等后台手动归0。封顶就是60，已经60单，就不能抢单了。任务开关不能去做归0操作。
  2. 小程序用户抢单接口修改，如果已经是60单，就不用返回新商品，但是参数还是一样，不要返回新商品就行，参数和正常的是一样。只是不要返回商品即可。
  3. 商品返回不用按照商品列表轮询，而是随机返回商品。比如后台有100个商品，小程序用户抢单接口返回商品时，随机返回100个商品中的一个。
  4. 商品返回不管是不是中文还是英文，就后台有什么商品就返回，不要限制英文还是中文，也不用管小程序用户设置的是中文还是英文。
